# Some Styling Improvements

Cyberpunks fun and all, but who can read this crayonbox?  I needed to fix the carto API key change, and wanted to scale up some of the tiny tags, while i was at it got inspired enough to make a light mode that is hopefully easier to read.

Accomplished stff

**Light Modde: ** 
Every page now has a light theme that's easier to read, with high-contrast text and deep, muted accent colors instead of neon on black. Dark mode looks the same as before.

**Remembers your choice:** 
The site remembers which theme you picked and applies it on every page, with no flash of the wrong theme when a page loads.

**PMP dashboard included:** 
The charts, map, timeline, and filters were partially hard-coded, but also now switch the theme, so the dashboard is readable in light mode too.

**Easier to read in both themes:** 
Text is larger overall, and the tags, badges, dates, table headers, and footer text that were too small are now legible. The thin nav and button text is bolder, which helps on large monitors.

Cleaner light mode: Removed the minty tint that covered the whole page, and made selected and hovered buttons solid and high-contrast.

**Map fix: CARTO:**  
started requiring an API key for its raster tiles around late August 2026, which stamped "API KEY REQUIRED" on every tile. Switched the map to Esri's Light Gray Canvas, which needs no key. The old CARTO setup is noted in the code in case I want to go back.

**Floating theme icon:** 
I 'made' these two Icons using Meshy 7, and setup the style and animation.  The small icon on the top-right corner replaces the initial placeholder button. The toggle stays faded and small until you hover, then grows and brightens, and it shows the icon for the mode you're in.
